A Case Study in Separation: The Wh-Suasive Frame

Purpose

This file documents a supplementary analysis of the wh-suasive frame {{WRB}} {{PRP<FPP1>}} {{VBP<PUBV><SUAV><VPRT>}}, one of two bundles excluded from the confirmatory regression analysis in the main text under the corrected DP criterion (Section 3.5; DP = 0.77, exceeding the DP ≤ 0.75 threshold). This bundle is examined here as a stress test of estimator behaviour under sparsity more extreme than any of the six modelled bundles exhibit (present in only 3.7% of files, versus 16.7%–69.5% for the modelled set). The result is a distinct and instructive failure mode — separation — that is conceptually different from the GLMM singular-fit issue discussed in Section 5.1 of the main text. Both frequentist estimators handle it identically, by correctly signalling the problem rather than either producing a misleadingly confident estimate; a supplementary Bayesian comparison, following Winter and Bürkner's (2021) recommended approach, shows that weakly informative priors can resolve this failure directly, recovering a genuinely interpretable developmental pattern that frequentist estimation could not access.

The mechanism: separation, not model complexity

The regression specification used throughout the main text treats NS as the reference level, meaning every level coefficient (A2, B1, B2) estimates a rate relative to the NS rate. Here, the NS rate is a true structural zero. A log-linear rate model cannot express "infinitely more common than zero" as a finite number: the optimiser instead drives the relevant coefficients toward extreme values in an attempt to approximate this, a textbook instance of quasi-complete separation.

Both estimators return coefficients in the 17–18 range on the log scale — exp(17.7) ≈ 4.9 × 10⁷, a physically meaningless rate ratio. Note also that levelB2 (+17.3, PPML) and levelB2:topicSMK (−17.4, PPML) very nearly cancel: this reflects the B2×SMK cell also being a true zero (1 occurrence in B2×PTJ, 0 in B2×SMK), so the model is simultaneously attempting to explode and cancel two separate zero-cells at once.

The two estimators fail in different but equally diagnostic ways. PPML's failure is quiet: the intercept and topicSMK terms carry deceptively tiny standard errors (~4 × 10⁻⁷), which could be mistaken for precision if one only checks the SE column and not the coefficient magnitude. GLMM's failure is loud: standard errors in the hundreds make the absence of real information immediately visible.

Simplified main-effects model

To rule out model complexity (an 8-cell saturated interaction model fitted to only 46 occurrences) as the driver, the same bundle was refitted without the interaction term:

The explosion persists (coefficients still in the 16–18 range) even after removing every interaction term. This confirms the mechanism is the structural zero in the reference cell itself, not the complexity of the interaction specification: no amount of simplification can produce a finite, meaningful estimate of "rate relative to a baseline of zero" under frequentist maximum likelihood.

Bayesian comparison (brms)

Winter and Bürkner (2021) specifically advocate Bayesian estimation for exactly this kind of sparse-data difficulty, arguing that weakly informative priors supply regularisation that the frequentist maximum likelihood lacks. This was tested directly on the wh-suasive frame's full interaction specification, using their own recommended prior convention on fixed effects:

library(brms)

weak_priors <- c(
  prior(normal(0, 0.5), class = "b"),
  prior(normal(0, 2),   class = "Intercept"),
  prior(exponential(1), class = "sd")
)

bayes_mdl <- brm(
  raw_count ~ level * topic + offset(log(file_wc)) + (1 | writer_id),
  data = model_sub, family = poisson(), prior = weak_priors,
  chains = 4, iter = 4000, warmup = 1000,
  control = list(adapt_delta = 0.99, max_treedepth = 15), seed = 42
)

Convergence is clean throughout: Rhat = 1.00 for every parameter, Bulk/Tail ESS in the thousands to tens of thousands, and zero divergent transitions across 12,000 post-warmup draws (4 chains × 4,000 iterations, 1,000 warmup). Every coefficient is finite and every credible interval is a usable interval — a striking contrast with the ±17–18-order explosion both frequentist estimators produced on the identical specification above.

The result is interesting in its own right. Exponentiating the two credible coefficients: A2 learners show a rate of this bundle approximately 2.39 times the (near-zero) NS baseline [exp(0.87)], and B1 learners approximately 2.36 times [exp(0.86)], both with 95% credible intervals excluding zero. By B2, the coefficient (0.04) is no longer credibly different from the NS baseline. This pattern — elevated use at A2 and B1 that is no longer statistically credible by B2 — parallels the "no longer detectable by B2" trajectory identified for M5 in the confirmatory analysis (Section 4.2.4 of the main text), though this single-bundle exploratory result has not been subjected to the same holdout robustness check applied to the six modelled bundles and should be read as suggestive rather than confirmatory.

Interpretation

This is a different problem from the GLMM singular-fit issue documented in Section 5.1 of the main text. That issue was an artefact of an incompletely specified panel — a data-construction problem, fixed by ensuring every file receives an explicit zero-count row. Separation is not fixable by any panel correction: it is a property of the true data-generating process itself, arising whenever an entire reference category has zero occurrences of the outcome. No frequentist estimator in the Poisson-GLM family — PPML, GLMM Poisson, or GLMM Negative Binomial — can produce a meaningful finite rate ratio against a zero baseline without additional regularisation; the Bayesian comparison above shows that weakly informative priors supply exactly this regularisation, recovering an interpretable result from the same underlying data. It remains a point in favour of both frequentist estimators that they fail identically and diagnostically here, rather than either silently returning a plausible-looking but spurious estimate.

The substantive finding this diagnostic surfaces is arguably more interesting than a regression coefficient would have been: native-speaker writers in this corpus never produce the wh-suasive frame at all (0 of 400 files), while learners produce it, rarely, at every proficiency level studied (46 total occurrences). The Bayesian model refines this picture further: learner-side use is credibly elevated above the NS baseline at A2 and B1, but is no longer credibly distinguishable from it by B2. This is a genuine developmental signal invisible to both frequentist estimators, and a categorical divergence — complete presence versus complete absence at the population level — qualitatively different from the rate-based underuse and overuse reported for the six modelled bundles in the main text. This is consistent with this bundle's independent exclusion from the confirmatory analysis under the corrected DP criterion (Section 3.5): a construction concentrated in a small, specific subset of the population (here, entirely absent from one population) is by definition not amenable to the same kind of rate-comparison modelling as a bundle in general use by both groups. The lexical realisation data above sharpens this picture further: even the bundle's rare learner-side usage is not a productively deployed structural pattern but is itself dominated by a single fixed formula (why I agree, 44 of 46 tokens), suggesting the wh-suasive frame functions, where it survives at all, as a memorised essay-opening variant rather than a genuinely available grammatical resource.
