# MDA Statistical Analysis Project

This project was generated by MDA Tagger and contains everything needed to
run group comparisons on your dimension scores in R.

## Data

`data/dimension_scores.csv` - one row per document, with:

- `doc_id` - document identifier
- `metadata` - the subcorpus/category label assigned during data upload
- `n_words` - word count (if available)
- `Dimension1` ... `Dimension5` - Biber MDA dimension scores

## Scripts

Run in order:

1. `R/01_import.R` - loads the data, checks structure.
2. `R/02_descriptives.R` - summary statistics and boxplots per dimension, by subcorpus.
3. `R/03_group_comparisons.R` - Analysis 1: one-way group comparison. Fits `Dimension ~ metadata` and reports the omnibus (ANOVA) test, plus diagnostic plots. Tells you IF your subcorpora differ.
4. `R/04_posthoc.R` - pairwise post-hoc comparisons (Tukey-adjusted, via emmeans) and effect sizes. Tells you WHICH subcorpora differ.

Each script writes its output (tables and plots) to `output/`.

## A methodological note

This project does not automatically decide which statistical test is
"correct" for your data, and does not put significance stars on everything
based on p < .05. The appropriate model depends on the structure of your
corpus and your research question. Please:

- Inspect the diagnostic plots in `output/diagnostics_*.png` before trusting the omnibus test - if residuals look non-normal or heteroscedastic, consider the non-parametric alternative (Kruskal-Wallis + Dunn's test, commented out in the relevant scripts).
- If a category has only one observation, R may warn "not plotting observations with leverage one" when generating diagnostic plots. This is expected and not an error - a single-observation group is fit perfectly by the model, so that point cannot usefully appear on a residuals-vs-leverage plot. Treat any comparison involving a singleton category with appropriate caution regardless.
- Consider effect sizes alongside p-values - a statistically significant but tiny effect may not be linguistically meaningful.

## Extending beyond a one-way design

### Analysis 2 - Factorial analysis

Use when your subcorpora represent combinations of two or more factors (e.g. learner_status x proficiency). Add the extra column(s) via a join in `01_import.R`, then:

```r
model <- lm(Dimension1 ~ learner_status * proficiency, data = scores)
anova(model)

library(emmeans)
emmeans(model, pairwise ~ learner_status * proficiency, adjust = "holm")
```

### Analysis 3 - Mixed-effects analysis

Use when multiple texts come from the same author, or there are other repeated/grouped observations:

```r
library(lme4)
model <- lmer(Dimension1 ~ metadata + (1 | author_id), data = scores)

library(emmeans)
emmeans(model, pairwise ~ metadata, adjust = "holm")
```
