## Data

`data/doc_lengths.csv` - one row per document:

- doc_id - document identifier
- metadata - the category label assigned during data upload
- n_words - total token count for that document (used to normalize counts)

`data/token_counts.csv` (if exported) - one row per document per feature:

- doc_id, metadata - as above
- feature - a lowercased word form (or space-joined n-gram of word forms)
- count - how many times that feature occurs in that document

`data/pos_counts.csv` (if exported) - same structure, but feature is a base
part-of-speech tag with MDA subtags stripped, wrapped in double braces to
match the tag-bundle syntax used elsewhere in MDA Tagger (e.g. {{NN}},
{{VBD}}), or a space-joined n-gram of these.

`data/tag_counts.csv` (if exported) - same structure, but feature is a full
tag string including MDA subtags, also brace-wrapped (e.g. {{NN<NN>}},
{{DT<DEMP>}}), or an n-gram of these.

Tokens with no recoverable tag are recorded as {{UNTAGGED}} at the pos/tag
level, kept separate from the word-form data so they never contaminate
token-level counts.

These tables are long and sparse: a document with no row for a given
feature had zero occurrences of it, not a missing value.

## Scripts

1. `R/01_import.R` - loads the data and prints a summary.
2. `R/02_kfa.R` - Key Feature Analysis (Egbert & Biber, 2023).
3. `R/03_dispersion.R` - Gries's Deviation of Proportions (DP).
4. `R/04_weighted_log_odds.R` - weighted log-odds with an informative
   Dirichlet prior (Monroe, Colaresi & Quinn, 2008).
5. `R/05_kld.R` - Kullback-Leibler divergence and per-feature contribution.

Each script has a `feature_level` variable near the top (`"token"`, `"pos"`,
or `"tag"`) - set it to whichever level(s) you exported. Each also has a
`reference_category` variable, `NULL` by default (runs the "vs. all others"
comparison); set it to a category name to also run a "vs. one reference"
comparison.

Each script prints its results table to the console before writing it to
`output/`, so you can inspect it directly in your R session as well.

## A methodological note

These four measures answer related but distinct questions, and are not
meant to be collapsed into a single "keyness score":

- **KFA** and **weighted log-odds** ask which individual features are
  most strongly associated with a category.
- **KLD** asks how different the overall feature distribution is between
  two categories.
- **Dispersion (DP)** asks whether a feature is spread across many
  documents or concentrated in a few - a feature with strong KFA or
  log-odds results but poor dispersion should be treated with caution.

## A note on 02_kfa.R specifically

The pooled standard deviation formula in this script is implemented as an
unweighted average of the two groups' variances (not weighted by sample
size). Verify this detail against your own copy of Egbert & Biber (2023)
before using KFA results from this script in a publication.
