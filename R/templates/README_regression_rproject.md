## Scripts

1. `R/01_import.R` - loads the data, lists available predictor columns.
2. `R/02_ppml.R` - Poisson pseudo-maximum-likelihood regression (default),
   via fixest::fepois(): heteroskedasticity-robust standard errors,
   following Santos Silva and Tenreyro (2006).
3. `R/03_glmm.R` - Poisson generalized linear mixed model: adds a random
   intercept for a grouping variable (e.g. author or learner) to account
   for repeated texts from the same writer.
4. `R/04_zip.R` - zero-inflated Poisson regression: use when a feature
   has more zero counts than a plain Poisson model predicts.

Each script models the count of ONE feature at a time. Near the top of
each script, set `target_feature` to one of the features printed when
you run it, and edit `predictors` to whichever columns in `doc_lengths`
you want in the model. `03_glmm.R` also needs `grouping_var` set to a
column identifying repeated observations.

Each script prints its results table to the console before writing it to
`output/`.

## Choosing between the three models

- Start with **02_ppml.R** as the default - it is the simplest and most
  widely used approach for corpus count data of this kind.
- Use **03_glmm.R** if multiple texts in your data come from the same
  author or writer, so texts cannot be treated as fully independent.
- Use **04_zip.R** if the feature you are modelling has an unusually
  high proportion of zero counts, which a plain Poisson model tends to
  under-predict.

These are not mutually exclusive diagnostic checks - inspect the
zero-count percentage printed by 04_zip.R and the singular-fit warnings
from 03_glmm.R regardless of which model you ultimately report, to
understand whether your chosen approach fits the data reasonably.
